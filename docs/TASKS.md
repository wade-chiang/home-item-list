# Task 清單

> 產品規格見 [PRODUCT.md](PRODUCT.md)，專案紀律見 [../CLAUDE.md](../CLAUDE.md)，確認過的畫面見 [prototype/p0.html](prototype/p0.html)。

分段交付的原則：**P1 結束時，家裡的濾網就要真的開始被這個 app 管理。** 後面每一段都是在已經運作的東西上加東西，而不是「全部做完才上線」。

| 階段 | 目標 | 結束時你得到什麼 | 狀態 |
|---|---|---|---|
| **P0** | 靜態原型 | 確認版面與流程對不對，再動工 | ✅ 完成 |
| **P1** | 最小可用 | 家裡的耗材真的開始被管理 | |
| **P2** | 資料完整 | 暫停、照片、花費、篩選與 icon 自選 | |
| **P3** | 手機 app | 不用主動開，手機會自己提醒 | |
| **P4** | 加值 | 拍照自動填、成本統計 | |

**每個階段開工前都要先過原型關卡**：該階段會出現的所有畫面與互動，先在原型中呈現並經使用者確認。見 CLAUDE.md「原型關卡」。
